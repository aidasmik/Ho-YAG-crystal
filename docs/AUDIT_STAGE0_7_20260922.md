## Verdict

The project has a useful, substantially working numerical foundation, but it is **not correct in every supported path and is not yet ready for trusted NN training targets**. The original 162 tests passed again, in 61.38 seconds. Nineteen additional independent probes were executed; six failed. Source inspection also identified a separate Stage 7 pump-duration binding error. Passing existing tests and converging an outer iteration do not establish physical validity or correctness of every stage interface.

No production solver was modified during this audit. `main` remains unchanged. The audit branch adds only the measurements script, execution workflow and report. Findings below are not represented as repaired.

## 1. High-priority integration error: population-axis mismatch

Stages 2P and 3 single-pulse propagation return `final_populations_by_slice` in `(nz,4,ny,nx)` order. Stage 4 signal propagation expects `(4,nz,ny,nx)`. Repetitive-pump outputs use the latter layout. The same field name therefore hides different array contracts.

When nz is not four, direct handoff generally raises a shape error. **When nz=4, the shapes coincide and the wrong interpretation is silently accepted.** `validate_population_field` renormalizes the wrong axis, concealing the mistake instead of rejecting it.

A real Stage 3 single-pulse output, with shape `(4,4,3,3)`, had a mean I7 fraction of **0.0010525166**. Direct Stage 4 validation interpreted it as **0.2423370440**. Maximum local population-fraction error was **0.7819656810**. The actual mean excitation was about 0.105%, not 24.2%. This can change an absorbing material into a fictitiously amplifying one.

Required repair: one canonical population layout; explicit conversion for legacy outputs; preferably a typed population object containing its axis contract. Validate local total density before any roundoff-only normalization. Add integration tests for nz=3,4,5, not merely isolated tests within each stage.

Scope: the affected path is single-pulse Stages 2P/3 → Stage 4. Stage 7's internal modal-state path does not use this handoff, so this finding alone does not invalidate the reported Stage 7 output.

## 2. High-priority diagnostic error: weak-signal reference discards phase

In `signal.py`, `propagate_structured_signal_saturated` constructs its comparison beam as

    sqrt(sum(abs(signal)**2, axis=0) * dt)

This is a real, nonnegative square root of fluence. It is not the original complex spatial field. A vortex or other phase structure is removed before the reference propagates through nonuniform gain and diffraction.

Independent test: LG(0,2), waist 65 micrometres, length 18 mm, radially nonuniform inversion, infinitesimal input energy. The correct complex-field weak gain was **1.0640083482**. The actual time-dependent signal solver approached **1.0640083482**, agreeing to **2.91e-13 relative**. The stored weak reference was **1.7157524830**, a **61.25% reference error**.

Required repair: propagate the original complex spatiotemporal input through the frozen-population model when computing the weak reference. Do not infer a unique field from intensity alone. A separable-pulse optimization may preserve a known spatial mode, but arbitrary space/time fields need the full reference operator.

Scope: the actual saturated field propagator passed the weak-field limit; the diagnostic reference is wrong. The 61% example is an intentionally phase-sensitive 18 mm stress test, not a measured error in the present 1 mm disk's output.

## 3. Source-confirmed Stage 7 configuration error: duration does not change pump spectral overlap

`run_coupled_hot_cavity` accepts `pump_duration_s`, but always constructs `FieldCoupledLaser` with `pump_absorption_m2=1.223454786e-24`. Duration reaches the short-kick validity check and metadata; it does not update that absorption value. Stage 5's modal helper similarly has a 10 ps default scalar absorption value.

The current surrogate gives approximately **1.22345e-24 m² at 10 ps** and **8.02577e-25 m² at 1 ps**. Therefore changing duration alone does not run the corresponding transform-limited spectral-overlap case. This is a source inspection finding additional to the six failed executable probes.

Required repair: centralize the pump specification, including wavelength, duration, actual bandwidth or spectrum, chirp convention and effective absorption. Compute the scalar overlap from that source, or require an explicit override with provenance. Do not assume chirped duration uniquely fixes bandwidth.

Scope: the existing default 10 ps value is appropriate for the current surrogate. Default 10 ps results are not automatically wrong because of this binding defect; duration sweeps are not trustworthy as currently wired.

## 4. Detuning sign: optical carrier and FFT frequency convention need to agree

NumPy's FFT represents positive bin frequency by exp(+i 2 pi f t). With the optical convention exp(+ikz-i omega t), a positive optical detuning multiplies the envelope by exp(-i Delta omega t) and appears at a negative FFT-bin frequency. The current spectroscopy routine uses `nu0 + fftfreq`, reflecting the detuned spectrum under that convention.

For a +200 GHz optical detuning, the expected effective cross section in the repository's own spectrum model was **7.1877583952e-25 m²**; the function returned **4.2371628424e-25 m²**, **41.05% below** it.

Required repair: explicitly define the analytic optical carrier/time convention and use one conversion between FFT bins and physical optical frequency everywhere. Under exp(+ikz-i omega t), use nu=nu0-fftfreq, or equivalently transform with the matching inverse-sign convention. Test positive and negative detuning against direct spectral integration. Centre-symmetric spectra cannot detect this issue.

The separate GDD complex-envelope test passed at 3.98e-16 relative error. Do not indiscriminately reverse the quadratic GDD phase while fixing the frequency labels; its even frequency dependence is a separate question.

## 5. Additional executable failures

### Incomplete parameter validation

`HoYAGFourLevelParams` accepts negative cross sections, negative lifetime, NaN total density, a negative multiphonon rate, and beta78=0.2 even though the inherited RHS assumes beta78=1. Defaults are valid, but automated parameter sweeps can silently leave the physical domain. Validate finite positive lifetimes/wavelength/density, nonnegative rates/cross sections and every branching-ratio contract at construction.

### Overflow before evanescent masking

Backward angular-spectrum propagation with `bandlimit=True` still evaluates the exponentially growing evanescent factor before setting those components to zero. On a subwavelength grid, a strict floating-point check raises `overflow encountered in exp`. Compute only the propagating transfer factors when masking is enabled. Reject or explicitly regularize backward evanescent continuation when it is requested. The normal macroscopic beam grids need not encounter this branch.

### Clipped density maps do not preserve requested statistics

The random-density generator clips, rescales to the desired mean, and clips again. The second clipping destroys the preserved mean. A strong-clipping stress case with requested relative RMS 1.2 and floor 0.6 returned mean/requested=**1.0544073751** and relative RMS=**0.5568569084**. This is not evidence of an error in the earlier modest 8% RMS example. Enforce the mean and lower-bound constraints together, report actual RMS, and reject unsupported specifications rather than promising all constraints simultaneously.

## 6. Quantified approximations: not the same as programming defects

### Spectrum averaging is only a limited attenuation approximation

Even without saturation,

    <exp(-N L sigma(nu))> != exp(-N L <sigma(nu)>).

The first expression is spectrally resolved weak-pulse transmission. The second is the effective-sigma implementation. Using the SAME Gaussian spectral surrogate in both calculations isolates this approximation:

| Pulse duration | Path length | Spectral transmission | Scalar transmission | Scalar relative bias |
|---:|---:|---:|---:|---:|
| 1 ps | 1 mm | 0.8867723 | 0.8851557 | -0.1823% |
| 1 ps | 2 mm | 0.7892955 | 0.7835007 | -0.7342% |
| 1 ps | 18 mm | 0.2061512 | 0.1112639 | -46.028% |
| 10 ps | 1 mm | 0.8303125 | 0.8303025 | -0.00120% |
| 10 ps | 2 mm | 0.6894355 | 0.6894023 | -0.00482% |
| 10 ps | 18 mm | 0.0353195 | 0.0351767 | -0.4044% |

These are absorption-only comparisons, not full cavity outputs or measured spectra. The current 10 ps thin-disk use is much safer than a 1 ps long-rod use. A previously small photon-energy-weighting correction does NOT establish that spectral reshaping at finite optical depth is negligible. Use spectrally resolved attenuation or a controlled bandwidth/optical-depth acceptance criterion.

### Coarse gain slices can violate the desired energy accuracy

An independent isolated two-level Frantz-Nodvik comparison used 3 J/cm² incident fluence and an 18 mm medium. Exact gain: **3.2212037971**.

| z slices | Relative gain error | Relative excitation/optical energy mismatch |
|---:|---:|---:|
| 1 | 2.750% | 7.107% |
| 4 | 0.1659% | 0.4176% |
| 16 | 0.00994% | 0.02551% |
| 64 | 0.0002406% | 0.001130% |

The numerical solver converges to the analytic limit. This is evidence for the underlying equations, but not for arbitrary coarse discretizations. Add convergence requirements or adaptive slice selection. This is an isolated mathematical test, not a claim that omitted Kerr/damage physics would be negligible at all such physical fluences.

### Optical grid and modal completeness remain unvalidated

For a 12 mm FFT window, a 500 mm-radius mirror and 2090.3 nm wavelength, the mirror phase increment at radius 5 mm is approximately 5.64 rad/pixel at 128 pixels and 3.76 rad/pixel at 192 pixels. Both exceed pi. At 256 pixels it is 2.82 rad/pixel; at 384 it is 1.88. This criterion applies at the stated disk radius, not everywhere on the larger square.

The central fundamental mode can still be resolved; these numbers do not prove the previous central mode is invalid. But the eigensolver explores a wider function space. Large/high-order/edge modes require optical-grid and window refinement, not just a tiny algebraic eigenpair residual.

No new full coupled hot-cavity grid-refinement or multimode stability study was run in this audit. The existing Stage 7 demonstration is a coarse-grid fixed point of an adiabatic modal model, not a proof of stable vortex operation or of experimentally accurate 0.753 W output.

## 7. Independent checks that passed

- Tilted plane-wave angular-spectrum propagation: relative complex error **4.23e-15**.
- Full complex Gaussian GDD solution, not just FWHM: relative error **3.98e-16**; energy error **2.22e-16**.
- Four-manifold RHS compared to independently enumerated stoichiometric events: relative error **1.66e-16**.
- Heat calculated from independent event energy changes, pump and signal quantum defects, compared to the implemented ledger: relative error **1.63e-16**.
- Arbitrary affine 3-D FEM displacement patch: maximum engineering-strain error **3.76e-19**.
- External pressure / interface action-reaction balance: relative error **7.82e-15**.
- Isotropic-limit photoelastic rotational covariance: relative error **1.37e-16**. The implemented tensor-shear factor is consistent in this test; it should not be labelled an error merely because another Voigt convention differs.
- Asymmetric finite crystal/plate thermal network with insulated and low-conductance patches: steady energy error **7.62e-14 relative**, transient error **1.60e-11**. The fully insulated interface patch carried exactly zero heat, and the plate was nonisothermal.
- Rigid translation and fixed-rear crystal expansion gave the expected reflected geometric paths; the vector round-trip phase check was accurate to **5.71e-16** in field norm.

These tests support the core rate/heat equations, propagation operators and finite plate/FEM machinery for their stated assumptions. They do not calibrate material coefficients or the physical mounting interface.

## 8. Cooling-plate and experimental-validity boundaries

The implemented interface is a bilateral, compliant BOND. A prescribed differential-heating case produced both signs of normal traction: roughly -0.885 MPa and +1.261 MPa. A bond may transmit tension; an unbonded contact cannot be presumed to remain closed under the same calculation. For a pressed or soldered real assembly, actual preload, opening/slip conditions, bond thickness/properties, residual fabrication stress and possible creep/plasticity matter. Thermal conductance is prescribed, not recomputed from mechanical pressure. These are declared model limitations, not a finding that equal/opposite force or thermal coupling is missing.

Heat still uses surrogate manifold/fluorescence energies. Thermo-optic and photoelastic coefficients, temperature-dependent spectra, radiation trapping and actual coating/contact losses are not calibrated for this sample. The original Rupp experimental validation was for a CW, 4 mm-diameter by 18 mm rod in a different resonator. It does not directly validate this reconstructed picosecond-pumped bonded thin disk.

## 9. Repair order and acceptance criteria

1. Fix the population handoff and phase-preserving weak reference. Require end-to-end single-pulse pump → signal tests, including nz=4 and nontrivial spatial phase.
2. Define one carrier-frequency convention and one physical pump specification shared by all stages. Add positive/negative detuning tests and 1 ps / 10 ps binding checks.
3. Strengthen parameter validation, density-statistics contracts and masked-propagation numerical guards.
4. Promote the independently reproduced failures into regression tests. Preserve pre-fix evidence; do not loosen tolerances to hide discrepancies.
5. Rerun affected amplifier results. Independently refine the full Stage 7 optical, material and mechanical meshes and retained-mode count. Distinguish converged discretized equations from physical validation.
6. Calibrate the real crystal/plate/bond/coolant and spectroscopy uncertainties before treating synthetic wavefront targets as ground truth.

Until then, use the model for exploratory calculations with explicit scope, not for final quantitative claims or NN training labels.
